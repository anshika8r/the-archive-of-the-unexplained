# Player guide

## Start with the book

Open the archive, then select **Resume the session** for Case I or **Break the seal** for Case II. On narrow screens use the Previous/Next page controls. Return to the archive at any time; each case saves its own progress in this browser.

## Case I: Desktop of a Stranger

1. Resume Ari's recovered session.
2. Single-click desktop icons to open applications. Drag a title bar on desktop to move a window. Use − to minimize, □ to maximize or restore, and × or Escape to close. Click taskbar labels to restore minimized apps.
3. Explore Notes, Photos, Messages and Trash. Read originals carefully and open annotations or attachments.
4. Restored files appear in Files → Recovered. Restore first, then open the restored file to recover its clue.
5. Collect all three fragments and enter them in A/B/C order in the locked file. Knowing the code alone does not bypass discovery.
6. Read the final testimony and choose an ending. Preserve keeps the recovered evidence; reset starts the reconstruction again with one new note. Replay is available in the top-left menu.

Sound is optional and starts off. Audio contains a recovered transcript. The Terminal is simulated; `help` lists the supported commands.

## Case II: Blackthorn Manor

1. Read the newspaper and unfold the investigation.
2. Open the dossier and suspect cards. Each suspect has a statement, motive, timeline and an explained secret.
3. Click evidence objects for readable close-ups. Close them using × or Escape. Show inspectable objects outlines the desk controls.
4. Compare ledger entries with signed receipts. Mark a discrepancy and inspect the gardener's statement to justify the search of Clara's writing case.
5. Use the notebook to review examined evidence, save personal notes or request progressive hints.
6. Arrange the timeline using selectors, then check it. Dragging is not required.
7. On the evidence board, choose two related records and connect them. Three supported deductions unlock the accusation.
8. Select a suspect, method and motive, then cite supporting evidence. Incorrect submissions explain what needs reconsidering without resetting progress.
9. Read the reconstruction and final report. The book stamps the case as solved; the completed dossier remains available.

## Saved progress

Progress is local to this browser and site origin. Moving between a local copy, GitHub Pages and ChatGPT Sites does not transfer it. Restart controls ask for confirmation and affect only that case. Browser privacy settings may prevent saving.
